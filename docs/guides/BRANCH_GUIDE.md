# Branch Guide:

Use following branches for now:
* staging
* staging-release-0.9.0

Main release branch (PR from staging-release-0.9.0 to this one when release is deemed ready):
* release-0.9.0

## Guide for agents:

### When making changes, checkout staging and create new branch based on agent name and number can be incremented if multiple agent branches exist for an agent:

#### For example:

* staging-baud-1
* staging-baud-2
* staging-ruffles-1
* staging-kageho-1
* staging-kageho-2
