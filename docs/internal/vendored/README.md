# Vendored upstream docs (archive)

These are **copies of third-party upstream project documentation** that were
accidentally swept into `docs/` by an earlier bulk commit
(`4ed60748 "Re-organized Documentation"`). They are **not LunarWing-authored**
and are kept here only to avoid losing history — nothing in the active docs tree
links to them.

| Subtree | Origin |
|---------|--------|
| `nanocode-config/` | The upstream **nanocode / opencode** project's own docs (READMEs, UI glossaries, package specs, test fixtures). Unrelated to LunarWing's `nanocode-config/` worker setup, which lives in the repo and is documented under `docs/guides/`. |

If you need the canonical version of any of these, consult the upstream project
directly rather than treating these snapshots as authoritative.
