# Custom Component Sources

components now also live **in-tree** (see the repo-structure list in the root `CLAUDE.md`); these
URLs are the original external repos they were developed in. Consolidated 2026-06-19 from the
scattered `custom_*` notes that previously lived in `docs/internal/`.

| WeeChat WSS channel | channel | `git.sobe.world/cmc/ironclaw_weechat_wss.git` |

| Gotify | tool | `git.sobe.world/cmc/gotify-wasm.git` |
