# Historical docs (archive)

Superseded LunarWing-authored documentation — raw session logs, "here's what I
changed" implementation summaries, and resolved fix/finding notes — relocated here
during the `docs/` reorg to keep the active tree focused on current, authoritative
material. Nothing here is a live reference; it's kept for provenance and history.

Organized by the `docs/` area each file came from:

| Subfolder | Origin |
|-----------|--------|
| `architecture/` | Implementation logs and resolved fix notes formerly in `docs/architecture/`. The authoritative current specs stayed in `docs/architecture/`. |
| `guides/` | Deprecated/divergent component docs formerly in `docs/guides/` (deprecated codex/nanocode workers, a divergent health-check snapshot, an unfilled GitLab-template README). |
| `internal/` | The abandoned stub scaffold formerly in `docs/internal/` — `custom_*` source-repo URL bookmarks, deprecated-codex notes, and empty/placeholder stubs. The substantial working docs stayed in `docs/internal/`. |

This is distinct from [`../vendored/`](../vendored/), which holds third-party
upstream copies that were never LunarWing-authored.
